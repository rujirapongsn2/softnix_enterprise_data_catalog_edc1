## หน้านี้คืออะไร {#what}

**ประวัติการตรวจสอบ (Audit Trail)** เป็นบันทึกแบบเพิ่มต่ออย่างเดียว (append-only) ที่ร้อยต่อกันด้วย hash ครอบคลุมการเปลี่ยน metadata การอนุมัติ การกระทำของ AI และการเรียก MCP tool เก็บไว้ 5 ปี ป้าย **Chain verified** ยืนยันว่าไม่มีรายการใดถูกแก้ไข

## วัตถุประสงค์และเป้าหมาย {#purpose}

- ตอบได้ว่าใครเปลี่ยนอะไร เมื่อไร จากค่าอะไรเป็นค่าอะไร และผ่านช่องทางไหน
- เป็นหลักฐานสำหรับผู้ตรวจสอบภายใน PDPA และหน่วยงานกำกับ

## ใครใช้หน้านี้ {#who}

ผู้ตรวจสอบและผู้ดูแลระบบ (ใช้ได้เต็มที่ รวมถึง export) DPO ก็ export ได้ ส่วน Steward, Owner, Custodian และคณะกรรมการดูได้อย่างเดียว

## วิธีใช้งาน {#how}

1. พิมพ์กรองตามผู้ใช้ ชุดข้อมูล หรือการกระทำในช่องค้นหา
2. เลือกประเภท: All actions, Approvals, Classification changes, AI-assisted, MCP calls และเลือกช่วงเวลา: Last 7 days หรือ Last 30 days
3. อ่านแต่ละแถว: Time, Actor, Action, Target, Old → New, Channel และ Hash
4. กด **Export for auditor** เพื่อรับไฟล์ที่ลงนามแล้ว (CSV + hash manifest)

## ฟิลด์และตัวชี้วัดสำคัญ {#fields}

- **Channel**: UI (ทำเองผ่านหน้าจอ), **AI** (ใช้ AI ช่วยและผู้ใช้กดยืนยัน) หรือ **MCP** (เรียกจากเครื่องมือ AI ภายนอก เช่น claude-desktop)
- **Hash**: ตัวเชื่อมของแต่ละรายการในห่วงโซ่ ถ้าห่วงโซ่ขาด แปลว่ามีรายการถูกแก้ไข

## งานที่ทำบ่อย {#tasks}

- พิสูจน์ว่าใครอนุมัติคำขอสิทธิ์และอนุมัติเมื่อไร
- ดึงรายการการแก้ไข metadata ที่ใช้ AI ช่วยทั้งหมดในช่วงเวลาที่กำหนด

## เคล็ดลับและคำถามที่พบบ่อย {#tips}

- ชุดข้อมูลแต่ละชุดมีประวัติของตัวเองที่แท็บ **ประวัติ (History)**
- ลบรายการออกจากบันทึกไม่ได้ การแก้ไขจะบันทึกเป็นรายการใหม่เสมอ
