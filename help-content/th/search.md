## หน้านี้คืออะไร {#what}

**หน้าค้นหา** แสดงชุดข้อมูลทั้งหมดในแคตตาล็อก (ตาราง, view, รายงาน, โมเดล ฯลฯ) ที่ตรงกับคำที่คุณพิมพ์ ค้นได้จากชื่อ คำอธิบาย คอลัมน์ คำศัพท์ธุรกิจ หรือแท็ก ทั้งภาษาไทยและอังกฤษ ตัวกรองด้านซ้ายช่วยคัดผลให้แคบลง

## วัตถุประสงค์และเป้าหมาย {#purpose}

- หาชุดข้อมูลที่ต้องการได้เร็ว และเลือกใช้เวอร์ชันที่เชื่อถือได้
- เปรียบเทียบตัวเลือกจากสถานะการรับรอง เจ้าของ ชั้นความลับ คุณภาพ และความสดใหม่ ก่อนนำไปใช้

## ใครใช้หน้านี้ {#who}

ทุกบทบาท ผู้ใช้ข้อมูลและนักวิเคราะห์ใช้มากที่สุด ส่วน Steward ใช้หาจุดที่ยังขาด เช่น ชุดข้อมูลที่ยังไม่มีเจ้าของ

## วิธีใช้งาน {#how}

1. พิมพ์คำค้นในช่องค้นหาแล้วกด **Enter** ระบบตัดคำภาษาไทยให้อัตโนมัติ
2. คัดผลด้วย **Filters**: Asset type, Domain, Certification, Classification, Personal data (PDPA), Layer และ Source system ตัวเลขด้านขวาบอกจำนวนผลของแต่ละค่า
3. ใช้ **Quick filters**: **Missing owner** (ยังไม่มีเจ้าของ) หรือ **Fresh (within SLA)** (ข้อมูลยังสดตาม SLA)
4. เปลี่ยนการเรียง (**Sort**) เป็น Relevance (ข้อมูลที่รับรองแล้วและนิยมขึ้นก่อน), Rating หรือ Data quality และสลับมุมมองแบบรายการหรือแบบตารางได้
5. คลิกการ์ดผลลัพธ์เพื่อเปิดหน้ารายละเอียด
6. ไม่แน่ใจว่าจะพิมพ์อะไร? กด **Ask in natural language** เพื่อถาม Softnix

## ฟิลด์และตัวชี้วัดสำคัญ {#fields}

การ์ดผลลัพธ์แต่ละใบแสดง:

- **ชื่อเชิงธุรกิจ** และชื่อทางเทคนิค พร้อม path เต็ม เช่น `lakehouse.gold.customer_360`
- ป้าย **Certified**, **Authoritative**, **Critical**, **PII / Sensitive** และ **AI draft metadata**
- **Domain**, **Owner** (ถ้ายังไม่มีจะขึ้น "Unassigned" สีแดง), **ชั้นความลับ**, **DQ %**, **Updated** (สีแดงถ้าเกิน SLA ความสดใหม่) และ **คะแนนรีวิว**
- กล่องคำแนะนำจาก AI ด้านบนผลค้นหา จะแนะนำคำศัพท์ที่ตรงกันและแหล่งข้อมูลหลัก (authoritative source) พร้อมบอกว่ามีชุดข้อมูล Restricted ถูกซ่อนตามสิทธิ์ของคุณกี่รายการ

## งานที่ทำบ่อย {#tasks}

- **Save search**: บันทึกคำค้นและตัวกรองไว้ใน "My saved searches"
- **Export**: ดาวน์โหลดรายการผลลัพธ์เป็น Excel
- เอาตัวกรองออกโดยคลิก × ที่ชิป หรือกด **Clear all**

## เคล็ดลับและคำถามที่พบบ่อย {#tips}

- **ทำไมไม่เจอตารางที่รู้ว่ามีอยู่?** อาจเป็นข้อมูล Restricted ที่ถูกซ่อนตามสิทธิ์ ให้ติดต่อเจ้าของข้อมูลหรือขอสิทธิ์
- ควรเลือกชุดข้อมูลที่เป็น **Certified** และ **Authoritative** เพราะมีเจ้าของ มีคำอธิบาย และยืนยันชั้นความลับแล้ว
- ถ้าเห็นข้อความ "No description yet — Steward action needed" แปลว่าชุดข้อมูลนั้นยังไม่มีคำอธิบาย
